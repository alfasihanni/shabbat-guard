# Shabbat Guard

מכבה אוטומטית את קמפייני המודעות הפעילים של חני אלפסי לפני שבת/חג, ומדליק אותם במוצאי שבת/חג — בענן, ללא תלות במחשב מקומי.

- **כיבוי:** ב-14:00 (שעון ישראל) ביום הדלקת הנרות (ערב שבת/חג).
- **הדלקה:** בצאת הכוכבים (הבדלה), לפי Hebcal — תל אביב.
- **על מי חל:** כל קמפיין שהיה `status=ACTIVE` ברגע הכיבוי. במוצ"ש מדליק בדיוק את אותם קמפיינים (לא מחייה ישנים).

רץ כל 15 דקות דרך GitHub Actions. הטוקן של Meta נשמר כ-Secret מוצפן (`META_ACCESS_TOKEN`) — לא בקוד. המצב נשמר ב-`state.json`.
